# Application Architecture Project

## Boekenwinkel

Dit project is een webapplicatie voor een fictieve boekenwinkel.

De applicatie laat gebruikers toe om boeken te bekijken, zich te registreren en aan te melden, boeken te reserveren en reviews te schrijven voor boeken die ze gekocht hebben.

## Projectstructuur

- `backend/` - De Spring Boot backend
- `frontend/` - De frontend van de applicatie
- `documentation/` - De technische documentatie
- `planning/` - De planning van het project

## Technologieën

### Backend
- Java
- Spring Boot
- Maven

### Frontend
- React

### Database
- MySQL
